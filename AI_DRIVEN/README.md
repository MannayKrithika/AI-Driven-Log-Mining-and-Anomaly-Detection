# AI-Driven Log Mining and Anomaly Detection

A cybersecurity project that uses Artificial Intelligence and Machine Learning to analyze system logs, detect anomalies, and provide insights for identifying potential cyber threats.

## Features

- Real-time log analysis
- AI-based anomaly detection
- Log visualization dashboard
- NLP-based log processing
- Trend analysis
- Machine learning models for threat detection

## Tech Stack

- Python
- Flask
- React
- Vite
- Machine Learning
- NLP
- JavaScript

## Project Structure

```text
AI-Driven/
├── Dashboard/

├── universal_forwarder/
└── README.md
```

## How to Run

### Frontend

```bash
cd Dashboard
npm install
npm run dev
```

### Backend

Run the required Flask server:

```bash
python flask_server.py
```
